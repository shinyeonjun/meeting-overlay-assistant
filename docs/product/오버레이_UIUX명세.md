# 오버레이 UI/UX 명세 (v2)

> 상태: **확정 (2026-10-13)**. 범위는 [제품 범위 전략 설계](제품_범위_전략설계.md)를 따른다.
> 색·크기 같은 시각 세부는 HUD 시안 확인 뒤 이 문서에 더한다.
> v1(준비·진행·정리·기록을 모두 오버레이가 맡던 명세)은 이 문서로 대체한다.

공식 클라이언트 경로는 `client/overlay/`다.

## 1. 오버레이가 맡는 것

오버레이는 **회의 중 화면**이다. 핵심 도메인인 실시간 자막을 보여 주고, 회의를 시작·일시정지·종료하는 일만 한다.

| 맡는다 | 맡지 않는다 (어디로) |
|---|---|
| 실시간 자막 (회색 → 확정) | 정본·전사본·녹음 재생 (웹) |
| 회의 시작·일시정지·재개·종료 | 리포트 생성·상태·보기 (웹) |
| 녹음 중 표시, 경과 시간 | 회사·상대방·스레드·참여자 (보류, 화면에서 숨김) |
| 질문·결정·액션·리스크 개수와 목록 (눌렀을 때만) | 이벤트 보정 (웹) |
| 설정: 입력 소스, 글자 크기, 배경 투명도, 서버 주소 | 운영 지표: 지연, 백프레셔, readiness 세부 (운영 콘솔) |
| 로그인 (로그인이 켜진 서버에서 처음 한 번) | "다음 액션" 요약, 현재 주제 (삭제) |

## 2. 원칙

1. **평소엔 작게, 필요할 때 펼친다.** 회의 전과 후에는 작은 바 하나만 떠 있다.
2. **자막이 주인공이다.** 회의 중 보이는 것은 자막과 작은 컨트롤 바뿐이다.
3. **이미 뜬 글자는 흔들지 않는다.** 확정된 줄은 다시 고치지 않는다. 진행 중인 줄만 바뀌고, 줄 위치가 튀지 않게 한다.
4. **읽기 쉬운 기본값.** 어두운 반투명 상자 위 밝은 글자. 뒤 창의 글씨가 자막과 겹쳐 보이면 안 된다.
5. **알아서 띄우지 않는다.** 인사이트는 개수만 보이고, 눌렀을 때 목록을 연다. 말하는 도중에 팝업을 띄우지 않는다.
6. **녹음 중임이 늘 보인다.** 녹음 중 표시는 접혀 있을 때도 보인다.
7. **운영자 정보는 보여 주지 않는다.** 사용자가 바로 행동할 수 있는 신호만 남긴다.

## 3. 화면 상태

| 상태 | 보이는 것 | 들어가는 조건 |
|---|---|---|
| **대기** | 작은 바: 시작 버튼, 입력 소스, 설정 | 앱 시작, 회의 종료 후 |
| **준비 안 됨** | 대기 바 + 이유 한 줄 (예: "음성 인식 준비 중", "서버에 연결할 수 없음"). 시작 버튼 비활성 | readiness가 준비되지 않음 |
| **진행 중** | 컨트롤 바 + 자막 영역 | 시작을 누름 |
| **진행 중 (접힘)** | 컨트롤 바만 (녹음 표시, 경과 시간 유지) | 사용자가 접음 |
| **일시정지** | 컨트롤 바에 "일시정지" 표시, 자막 영역 흐리게 | 일시정지를 누름 |
| **연결 끊김** | 컨트롤 바에 경고 표시와 다시 연결 버튼 | 실시간 연결이 끊김 |
| **종료 직후** | "기록은 웹에서 볼 수 있습니다" 안내와 열기 버튼. 몇 초 뒤 대기로 돌아감 | 종료 확인 |
| **설정** | 설정 시트 | 설정 버튼 |
| **로그인 필요** | 로그인 시트 (서버 주소 포함) | 로그인이 켜진 서버이고 로그인 전 |

## 4. 구성 요소

### 4.1 컨트롤 바
- 녹음 중 표시와 경과 시간
- 입력 소스 표시 (시스템 오디오 / 마이크 / 둘 다)
- 인사이트 개수 표시: 질문·결정·액션·리스크 합계. 누르면 목록을 연다. 0이면 숨긴다
- 일시정지/재개, 종료, 접기/펼치기, 설정
- 바를 끌어 옮길 수 있고 위치를 기억한다

### 4.2 자막 영역
- 최대 3줄을 보인다. 위 2줄은 최근 확정 자막, 마지막 줄은 진행 중인 회색 자막이다.
- 왼쪽 정렬이고, 새 줄은 아래에 붙고 오래된 줄이 위로 밀려난다.
- 회색 자막은 흐린 색, 확정 자막은 밝은 색이다. 회색 줄이 확정되면 **같은 자리에서** 글자와 색만 바뀐다.
- 화자 정보가 없으면 화자 표시를 붙이지 않는다 (지금처럼 모든 줄에 "LIVE:"를 붙이지 않는다). 화자 정보가 생기면 화자가 바뀔 때 한 번만 표시한다.
- `late_archive_final`은 화면 줄을 덮어쓰지 않는다. 기록에만 반영한다.
- 지난 자막은 위로 스크롤해 볼 수 있다 (최근 몇 분).

### 4.3 인사이트 목록
- 개수 표시를 눌러야 열린다. 자막 영역 위나 옆에 작게 뜬다.
- 항목: 종류(질문·결정·액션·리스크), 한 줄 내용, 근거 자막 시각
- 오버레이에서는 "처리 완료"만 할 수 있다. 수정은 웹에서 한다.

### 4.4 설정 시트
- 입력 소스 (기본: 시스템 오디오)
- 글자 크기, 배경 투명도 (기본값은 뒤 글씨가 비치지 않는 수준)
- 서버 주소 (control, live). 저장한 값과 환경 변수 중 어느 쪽을 쓰는지 표시하고, 기본값으로 되돌리는 버튼을 둔다
- 앱 정보 (서버 연결 상태)

## 5. 동작 규칙

- **시작은 한 번.** 시작을 누르면 회의를 만들고 바로 시작한다. 제목은 `YYYY-MM-DD HH:mm 회의`로 자동으로 정한다.
- **종료는 확인을 받는다.** 종료하면 되돌릴 수 없기 때문이다.
- **마우스는 오버레이 요소 위에서만 잡힌다.** 나머지 영역은 뒤 창으로 클릭이 통과한다.
- **앱을 닫으면 캡처를 끝낸다.** 오디오 캡처 프로세스가 남으면 안 된다.
- 화면 공유 때 오버레이 숨기기는 나중에 설정으로 더한다.

## 6. 화면에서 빼는 것 (v1 대비)

| 빼는 것 | 이유 / 옮기는 곳 |
|---|---|
| 첫 화면의 서버 연결·로그인 패널 | 설정 시트, 로그인이 켜진 서버에서만 로그인 시트 |
| "회의 준비" 단계 (제목 입력, 초안 만들기) | 원클릭 시작 |
| 고급 설정: 회사·상대방·스레드·참여자 후보·후속 작업 | 보류 (서버 유지) |
| "다음 액션" 요약 | 원클릭 흐름에서 필요 없음 |
| 현재 회의 정보 (현재 주제, 참여자 요약) | 주제 이벤트가 꺼져 있어 늘 비어 있음 |
| 리포트 상태 | 웹. 종료 직후 안내 한 번 |
| 숨긴 운영 지표 블록 | 운영 콘솔 |
